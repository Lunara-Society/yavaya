# Implementation status

Last updated in Chapter 01 (the existing architecture audit), 26 November 2026.

The complete classification of the **website's** systems (accounts, districts,
publishing, YavayaGo, Roxi, payments, tokens, notifications, admin) and how the
app should carry each one is the preservation matrix in
[BASELINE_AUDIT.md](BASELINE_AUDIT.md) §3. This file tracks the **mobile** work.

States: **REAL** works and was verified · **DEMO** works with sample content,
labelled · **MOCK** simulated, never shown as real · **BLOCKED** cannot work
until something outside the code changes · **NOT IMPLEMENTED** not built.
