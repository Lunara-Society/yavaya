Privacidad

Privacidad de este sitio

Este sitio es informativo. No tiene cuentas, formularios, cookies ni analítica.

Qué guardamos

Nada sobre ti. Este sitio no tiene cuentas ni formularios, y no usa cookies ni herramientas de analítica o publicidad.

Lo que guarda tu navegador

Si eliges un idioma o un tema (claro u oscuro), tu propio navegador lo recuerda en su almacenamiento local. Nunca sale de tu dispositivo y puedes borrarlo cuando quieras.

  • yavaya-lang: el idioma que elegiste.
  • yavaya-theme: el tema que elegiste.

Alojamiento

El sitio se sirve desde GitHub Pages. Como cualquier servidor web, GitHub puede registrar datos técnicos de las visitas, como la dirección IP, por razones de seguridad. Las fuentes tipográficas están alojadas aquí mismo, así que no se contacta a ningún otro servicio.

La plataforma

Cuando la plataforma Yavaya abra, tendrá su propia política de privacidad, publicada antes de que se pueda crear la primera cuenta.
